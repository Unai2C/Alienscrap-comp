# Design Decisions

2026-08-30 · Alien Scrapyard is competitive-first, not collaborative-first · The main motivation should be scoring, ranking, MVP status, crystals, artifacts and visible superiority; shared building remains the arena where competition happens.
2026-08-30 · [agent-decided · accepted] GDD work will include targeted prototype/playtest checks when a claim is risky · Alien Scrapyard already has playable systems, so the document should not invent confidence where quick tests can prove or kill an idea.
2026-08-30 · Alien Scrapyard competition is strategic efficiency, not pure speed · Players should win by choosing the right pieces, placing accurately, timing artifacts and managing cooldowns better than others.
2026-08-30 · [agent-decided · accepted] Artifacts are optional tactical boosts inside the core loop, not a mandatory step every cycle · This keeps the base arcade action readable while still giving skilled players a strategic edge.
2026-08-30 · [agent-decided · accepted] Alien Scrapyard's social design is live rivalry plus persistent player traces · Live rivals create pressure when players overlap, while leaderboards, trophies and records keep the world socially readable during quiet hours.
2026-08-30 · [agent-decided · accepted] Player-count target is solo playable, social from 2 players, ideal at 4-8, tested maximum 20 · This fits quiet Decentraland hours while keeping a clear performance target for mobile and desktop.
2026-08-30 · Drop-in/drop-out should never break a round · Late players can enter the queue for the next round, and leaving players do not erase placed pieces or stop remaining players from scoring.
2026-08-30 · [agent-decided · accepted] Bring-a-friend is competitive, not cooperative · A friend makes the arena harder and more exciting by becoming a rival, increasing pace and making MVP harder to win.
2026-08-30 · [agent-decided · accepted] Main return hooks are weekly leaderboard reset and collection/upgrades · The weekly reset gives a remembered competitive deadline, while crystals, scrap, artifacts and visible upgrades give longer-term progression.
2026-08-30 · Mobile controls map the full core loop to large touch targets · Piece selection, placement, cooldown reading, artifacts and round results must all work without precision aiming or small UI.
2026-08-30 · [agent-decided · accepted] Alien Scrapyard lore stays minimal and arcade-first · The world only needs to explain unstable alien scrap, timed builds, reclaimers, crystals, score and status.
2026-08-30 · [agent-decided · accepted] Comparables are Overcooked and Fall Guys · Overcooked anchors short chaotic task pressure, while Fall Guys anchors short competitive replayable rounds; Alien Scrapyard differs by making efficient building the competition.
2026-08-30 · First group arrival uses Discover, weekly leaderboard events and community links · Weekly races concentrate players, while solo play still works through saved records when no event is active.
2026-08-30 · [agent-decided · accepted] v1 scope focuses on balance, tutorial, ranking, shop, artifacts, mobile UI and optimization · Advanced park upgrades, full seasons and a large artifact catalogue stay out of v1 so the competitive loop can ship polished.
2026-08-30 · [agent-decided · accepted] Requested round is v1 · The repo already has a playable SDK7 core loop, so the request is for polish, balance, mobile readiness and World deployment rather than initial discovery.
